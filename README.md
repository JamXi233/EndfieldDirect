# EndfieldDirect

中文说明 | [English](README.en.md)

直接启动《明日方舟：终末地》（Arknights: Endfield），不需要打开官方启动器。

非官方项目，与鹰角网络（Hypergryph）无关。使用前请阅读"风险说明"。

## 功能

- 直接启动终末地，不需要打开官方启动器。
- 隐藏启动器窗口，并清除它的托盘图标。
- 通过 `-sc` 生成带游戏图标的快捷方式，并保存其余启动参数。
- 可以作为非 Steam 游戏添加到 Steam 中使用。Steam 悬浮窗、F12 截图和第三方性能监视器的叠加显示，在作者的环境中测试可用。
- 通过启动参数设置游戏的文字和语音语言。
- 单个 exe，约 35 KB，无需安装。

## 使用方法

1. 把 `EndfieldDirect.exe` 放到官方启动器所在的目录，即与 `Launcher.exe` 同一个文件夹。找不到启动器时，程序会弹窗提示。
2. 运行程序，在 UAC 提示中确认管理员权限。

### 生成快捷方式

```text
EndfieldDirect.exe -sc -wait=5
```

上面的命令会在桌面生成名为 "Endfield Direct" 的快捷方式，图标为游戏图标，启动时带上 `-wait=5`。

`-sc` 有三种写法：

| 写法 | 效果 |
|---|---|
| `-sc` | 放到桌面 |
| `-sc 文件夹路径` | 放到指定文件夹 |
| `-sc=路径\名字.lnk` | 指定完整路径和文件名 |

命令行中除 `-sc` 以外的参数都会保存到快捷方式里。快捷方式指向当前 exe 所在的位置，移动 exe 后需要重新生成。

### 在 Steam 中使用

选择"添加非 Steam 游戏"，浏览并选中 `EndfieldDirect.exe`。需要参数时，填写在该条目属性的"启动选项"中。

正常情况下不需要加 `-hold`，Steam 也会显示游戏正在运行并统计游玩时长（在作者的环境中测试）。只有当 Steam 的运行状态或时长没有生效时，再加上 `-hold`，让程序一直等到游戏退出。

## 参数

| 参数 | 说明 |
|---|---|
| `-sc` | 生成带游戏图标的快捷方式，其余参数一并保存，写法见上 |
| `-wait=N` | 游戏窗口出现后再等待 N 秒才收尾，默认 `3`。`0` 秒通常不行 |
| `-timeout=N` | 等待游戏窗口出现的最长时间（秒），默认 `60` |
| `-hold` | 等游戏退出后才关闭启动器 |
| `-dry-run` | 只显示将要执行的操作，不实际启动（与 `-sc` 同用时不创建快捷方式） |
| `-v` / `-verbose` | 输出详细日志，带时间戳 |
| `-lang=zh` / `-lang=en` | 指定界面语言，默认跟随系统语言 |
| `-language_text_change=N` | 写入文字语言注册表项 |
| `-language_audio=N` | 写入语音语言注册表项 |
| `-launcher_xxx=值` | 覆盖启动器参数，默认带 `-launcher_lang=zh-cn -launcher_sub_channel=1` |
| 其他参数 | 原样传给游戏，例如 `-force-d3d11` |

语言设置通过修改 `HKCU\Software\Hypergryph\Endfield` 下已有的注册表项生效，因此需要先用官方启动器运行过一次游戏，让这些项存在。

## 工作原理

1. 在后台启动官方 `Launcher.exe`，等待它拉起 `Games.exe`。
2. 以 `Games.exe` 为父进程启动 `Endfield.exe`，使游戏认为自己由官方启动器启动。
3. 用窗口事件钩子在启动器窗口显示的瞬间将其隐藏，并注销它的托盘图标。
4. 游戏窗口出现并等待缓冲时间后，先请求启动器正常退出，超时才强制结束。

## 风险说明

- 父进程伪装绕过了游戏"必须由官方启动器启动"的检查。这可能违反游戏的用户协议，也可能随游戏更新而失效。是否使用、后果如何，请自行判断并承担。
- 本程序只改变启动器和游戏的启动方式，不修改游戏文件，也不向游戏进程注入代码。
- 程序需要管理员权限，并会读取任务栏通知区的信息来注销启动器的托盘图标。
- 只会关闭位于启动器安装目录下的 `Games.exe` 和 `Launcher.exe`，不影响其他程序。
